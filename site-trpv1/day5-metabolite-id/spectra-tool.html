How to use this exercise

For each candidate, the parent compound is given (structure, formula, and reference ¹H NMR / MS/MS spectra). Each candidate then has one proposed Phase I metabolite, and three candidates (D16, D19, D22) additionally have a Phase II conjugate derived from that Phase I metabolite. These metabolites are presented as unknowns: only their simulated spectra and peak tables are shown. Using the parent's spectra as a reference, propose the metabolite's structure, the likely enzyme/pathway, and the site of biotransformation.

Tip: every parent structure shares a common piperazinyl-arylamine “core” and an acyl/aroyl “tail” cap. In the MS/MS data, compare which fragment (Core+H⁺ or Tail+H⁺) has shifted mass relative to the parent — that tells you which half of the molecule was modified. Two metabolites in this set (D19-M1 and D22-M1) shift the same fragment by the same mass — you will need the NMR data, not just MS/MS, to tell them apart. Glucuronide (Phase II) spectra show a diagnostic [M+H−176]⁺ neutral-loss ion that reproduces the corresponding Phase I metabolite's own [M+H]⁺ mass exactly.

D16 Ca2+ IC50 26.0 nM; lowest hyperthermia signal (ΔT 0.3°C) but not recommended -- TRPA1=43.5% at 10uM is a borderline selectivity flag.

  • All 6 parent structures are taken directly from the existing compound library (Workshop 6 clinical candidates D16/D18/D19/D20/D21/D22). All metabolite structures, exact masses, MS/MS fragment assignments and ¹H NMR peak lists were newly derived for this workshop (RDKit-validated formulas and exact masses; hand-assigned NMR shifts using standard empirical correlation ranges).
  • Every metabolite's total ¹H count reconciles exactly with its calculated molecular formula (verified programmatically).
  • MS/MS fragmentation model: each parent/metabolite is split into a shared piperazinyl-arylamine “Core” fragment and an acyl/aroyl “Tail” fragment at the exocyclic amide C–N bond; whichever side carries the proposed biotransformation shows the corresponding mass shift, letting students localise the change from the fragment pattern alone. Glucuronide conjugates show the classic [M+H−176]⁺ neutral loss of anhydroglucuronic acid.
  • Relative intensities, exact m/z values, and NMR chemical shifts are illustrative teaching constructs, not measured or literature-derived data. All compounds are entirely fictional.
  • Spectra are rendered as inline SVG from embedded data — no external libraries or internet connection required.
