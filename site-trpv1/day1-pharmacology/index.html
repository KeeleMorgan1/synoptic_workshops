Task 2 — Orthogonal Assay Comparison
Task: TRPV1 can be probed in several different ways: Ca²⁺ flux (functional, measures downstream Ca²⁺ accumulation), patch-clamp electrophysiology (measures the channel current directly), and acid-evoked activation (a distinct activation mode from capsaicin). You have been given summary data for 4 compounds across all of these readouts, plus a selectivity panel against three related ion channels and a voltage-gated sodium channel. Write a short report comparing and interpreting these compounds.

Ca²⁺ flux and patch-clamp IC50s are both single-point summary values (not concentration-response curves) for these four compounds — the raw curve data you need for curve-fitting practice is in Task 1 above; this task is about comparing assay modalities and selectivity, not re-fitting curves.
